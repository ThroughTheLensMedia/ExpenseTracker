# Acceptance Checklist

The rebuild is only complete if all of the following are true.

## Core business clarity
- [ ] Monthly business performance is obvious at first glance
- [ ] Yearly performance can be reviewed clearly
- [ ] Business and personal views are separable
- [ ] Forecast is below actuals

## Core visual changes
- [ ] Doughnut chart has been removed from expense allocation
- [ ] Expense categories use a scalable ranked chart
- [ ] Revenue, expenses, and net profit appear in one primary performance view
- [ ] Layout hierarchy prioritizes actuals before forecast

## Recurring intelligence preservation
- [ ] Recurring Vendor Activity remains on dashboard
- [ ] Recurring Monthly Bills remains on dashboard
- [ ] Rocket Money-style recurring analysis value is preserved
- [ ] Cancel candidates can be flagged
- [ ] Business/personal leakage can be identified in recurring spend

## Data reliability
- [ ] KPI totals reconcile to underlying data
- [ ] Monthly summaries reconcile to transactions
- [ ] Recurring vendor totals reconcile to source data
- [ ] Bill prediction logic is reasonable and reviewable

## Interaction quality
- [ ] Major widgets support drill-down
- [ ] Tables are sortable and readable
- [ ] Filters work consistently across widgets
- [ ] Dashboard remains performant in production
